## 1.1. 10 способов записи числа 42 (литералы)
В Python можно записать число 42 разными способами без использования арифметики и функций, используя только литералы:

* Десятичный формат: 42
* Десятичный с разделителем: 4_2
* Двоичный формат: 0b101010
* Двоичный с разделителем: 0b10_1010
* Восьмеричный формат: 0o52
* Шестнадцатеричный формат: 0x2a
* Число с плавающей точкой: 42.0
* Экспоненциальная запись: 4.2e1
* Экспоненциальная запись (вариант 2): 0.42e2
* Комплексное число: 42+0j

Примечание: Выражения вроде 42.0 == 42 или 42+0j == 42 возвращают True.

## 1.2. Ограничения на диапазон чисел

* Целые числа (int): В Python 3 не имеют ограничений на размер. Они ограничены только объемом доступной оперативной памяти компьютера.
* Числа с плавающей точкой (float): Ограничения существуют. Они используют стандарт IEEE 754 (двойная точность, 64 бита).
* Максимальное значение float: Составляет примерно 1.7976931348623157e+308. При попытке получить большее число произойдет ошибка OverflowError либо значение превратится в бесконечность (inf). Узнать точное значение на вашей системе можно через sys.float_info.max.

## 1.3. Встроенная функция, возвращающая два значения
Такой встроенной арифметической функцией является divmod(a, b).

* Она принимает два числа и возвращает кортеж из двух значений: частное от деления и остаток от деления (a // b, a % b).
* Пример: divmod(13, 4) вернет (3, 1).

Почему программа зависает без циклов?Код из примера: pythonz = 1
z <<= 40
2 ** z
Используйте код с осторожностью.Причина зависания: Операция z <<= 40 сдвигает единицу на 40 бит влево, превращая z в огромное число \[2^{40}\] (это 1 099 511 627 776).Следующая строка 2 ** z пытается вычислить \[2\] в степени \[2^{40}\]. То есть \[2^{1099511627776}\].В Python целые числа могут быть бесконечно большими, но для хранения такого числа в памяти потребовалось бы около 137 гигабайт оперативной памяти. Программа «зависает», так как интерпретатор тратит все ресурсы процессора и памяти на попытку выделить это место и вычислить гигантское число. 1.6. def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
